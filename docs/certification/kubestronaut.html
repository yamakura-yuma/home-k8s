Tier 1

Kubestronaut

Kubernetes 系 5 資格 (KCNA / KCSA / CKA / CKAD / CKS) を同時に有効な状態で保持している人に CNCF が与える称号。 取得順や取得時期は問われない。資格が 1 つでも失効すると、その年の年末で称号も失う「維持型」の称号。

推奨する取得順

CKS は有効な CKA が受験条件。KCNA → KCSA で用語を固め、CKA で実技に慣れてから CKAD、最後に CKS が定番。 CKA 合格で KCNA が、CKS 合格で KCSA と CKA が自動更新されるので、この順なら更新の手間も最小。

維持ルール

称号は「いずれかの資格が失効した暦年の末」まで有効。年内に更新すれば継続。

更新を最小化する

  • 全資格 2 年有効。5 つをバラバラに更新すると毎年何かを受け直すことになる
  • CARE により CKS 合格 → KCSA / CKA / KCNA を自動更新 (2026-06-18〜)、CKAD 合格 → KCNA 更新
  • つまり 2 年ごとに CKS と CKAD の 2 つを取り直せば 5 資格すべて維持できる

失効したら

  • 10 月に CNCF からリマインドメール。年末までに更新すれば称号は途切れない
  • 失効後に再び 5 資格をそろえれば特典は復活するが、ジャケットは再支給なし
  • Golden 称号自体は失わないが、Golden の年次特典 (THRIVE-ONE 等) は止まる

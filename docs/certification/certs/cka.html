試験の画面イメージ

PSI Secure Browser 経由で Linux リモートデスクトップに接続し、ターミナルで実際に操作する試験。各タスクで指定ノードに ssh し、設定変更やリソース作成を行う。部分点あり。結果は 24 時間以内にメール。

何が問われるか

  • kubeadm によるクラスタ構築・アップグレード、etcd バックアップ / リストア
  • RBAC、Helm / Kustomize、CRD と Operator、HA コントロールプレーン
  • Gateway API / Ingress、NetworkPolicy、CoreDNS、CNI
  • ノード・コンポーネント・ネットワークの障害切り分け (配点 30%)

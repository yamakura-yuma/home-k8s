試験の画面イメージ

PSI Secure Browser 経由で Linux リモートデスクトップに接続し、ターミナルで実際に操作する試験。各タスクで指定ノードに ssh し、設定変更やリソース作成を行う。部分点あり。結果は 24 時間以内にメール。

何が問われるか

  • istioctl / Helm でのインストール、Sidecar モードと Ambient モード、Canary アップグレード
  • Gateway / VirtualService / DestinationRule、トラフィック分割、外部サービス
  • リトライ・タイムアウト・サーキットブレーカ・フォールトインジェクション
  • PeerAuthentication (mTLS)、RequestAuthentication (JWT)、AuthorizationPolicy

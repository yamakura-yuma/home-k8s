試験の画面イメージ

PSI Secure Browser 経由で Linux リモートデスクトップに接続し、ターミナルで実際に操作する試験。各タスクで指定ノードに ssh し、設定変更やリソース作成を行う。部分点あり。結果は 24 時間以内にメール。

何が問われるか

  • Argo CD / Flux による GitOps、Argo Rollouts / Flagger によるプログレッシブデリバリー
  • CRD / Operator / Crossplane によるセルフサービス API、Backstage 連携
  • Prometheus / OpenTelemetry / Grafana / Jaeger による可観測性、OpenCost
  • Kyverno / OPA Gatekeeper によるポリシー、RBAC、Secret 管理

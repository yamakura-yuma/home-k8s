試験の画面イメージ

PSI Secure Browser 経由で Linux リモートデスクトップに接続し、ターミナルで実際に操作する試験。各タスクで指定ノードに ssh し、設定変更やリソース作成を行う。部分点あり。結果は 24 時間以内にメール。

何が問われるか

  • マルチコンテナパターン (init / sidecar)、Job / CronJob、Volume
  • Deployment のローリングアップデート / ロールバック、Helm / Kustomize
  • ConfigMap / Secret、SecurityContext、ServiceAccount、Resource / Quota
  • Probe、ログとデバッグ、Service / Ingress / NetworkPolicy

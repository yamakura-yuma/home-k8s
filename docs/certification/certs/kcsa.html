何が問われるか

  • 4C (Cloud / Cluster / Container / Code) モデルと信頼境界
  • API server / etcd / kubelet / scheduler など各コンポーネントの守り方
  • 認証・認可 (RBAC)・Admission Control、Pod Security Standards
  • 脅威モデル (権限昇格・DoS・サプライチェーン)、NIST / MITRE ATT&CK 等

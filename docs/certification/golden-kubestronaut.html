攻め方

追加 11 資格の順序は自由。Kubestronaut 到達後はクーポンが毎年 5 枚出るので、2 年で 10 枚 = 追加分ほぼ全部を半額で受けられる。

Phase 1
Kubestronaut 5 資格
まず青ジャケット。以後 50% off クーポンが毎年 5 枚
→
Phase 2
選択式 Associate 8
PCA / CCA / CAPA / CGOA / CBA / OTCA / KCA / CNPA。1 つ $250、各 90 分。クーポンで半額
→
Phase 3
実技 3
ICA (Istio)・CNPE (プラットフォーム)・LFCS (Linux)。CNPE は CKA/CKS の延長線、LFCS はブラウザなし
要注意: 16 資格が「同時に有効」である必要がある。5 冠が 2 年で切れ始めるので、Golden 到達の直前に Kubestronaut 側の更新 (CKS / CKAD) を済ませておかないと、最後の 1 つを取った時点で最初の資格が失効している、という事故が起きる。

要件の変遷

新資格は GA から 90 日以上経ってから要件に加わる (施行日はプログラムページに掲示)。既に Golden の人は追加要件を満たす必要がない。

#48: headroom の HEAD

HEAD を使う用途は無い (Pod の probe は tcpSocket)。HEAD→GET への書き換えは、HEAD の応答に本文を返しうるので採らなかった。just/share-relay.Caddyfile と clusters/kind/share/Caddyfile の両方で GET だけにし、どちらの試験でも「許可リストの経路への HEAD は 404 で upstream に届かない」を確かめる。

4. #56: Backstage の Basic が引数に出ない

変更前変更後
kubectl ... create secret generic backstage-grafana \
  --from-literal=GRAFANA_BASIC_AUTH="$(… | base64 -w0)"
# → ps に base64 の値が出る
 
printf 'backstage:%s' "$(cat "$backstage_file")" | base64 -w0 >"$tmp/basic"
kubectl ... create secret generic backstage-grafana \
  --from-file=GRAFANA_BASIC_AUTH="$tmp/basic"
# → 一時ファイル (077) を終了時に消す。引数にも注釈にも値が無い

試験: 引数に base64 の値が無いこと、--from-literal で渡してよいのは秘密でない値 (admin-user・SHARE_RELAY_ADDR) だけという静的な見張り。
